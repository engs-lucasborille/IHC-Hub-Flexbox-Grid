Flexbox: layouts em uma dimensão

O que é Flexbox?

O CSS Flexible Box Layout, ou Flexbox, organiza elementos em uma dimensão: em uma linha ou em uma coluna. Ele facilita o alinhamento, a distribuição de espaço e a adaptação dos itens quando o tamanho da tela ou do conteúdo muda.

Para começar, aplique display: flex; ao elemento pai. Ele se torna o contêiner flexível, e seus filhos diretos passam a ser itens flexíveis. 

.container {
  display: flex;
}

Eixos e direção

O eixo principal é definido por flex-direction. Por padrão, os itens ficam em uma linha (row); com column, são empilhados em uma coluna. O eixo transversal é perpendicular ao principal.

1
2
3
.container {
  display: flex;
  flex-direction: row; /* row, row-reverse, column ou column-reverse */
}

Alinhamento e espaçamento

justify-content distribui os itens no eixo principal. Já align-items os alinha no eixo transversal. Use gap para definir o espaço entre itens sem adicionar margens individuais.

Início
Centro
Fim
.container {
  display: flex;
  justify-content: space-around;
  align-items: center;
  gap: 1rem;
  min-height: 180px;
}
  • justify-content: flex-start, center, space-between, entre outros.
  • align-items: stretch, center, flex-start ou flex-end.
  • align-self altera o alinhamento transversal de um item específico.

Quebra de linha e itens flexíveis

Por padrão, os itens tentam permanecer em uma linha. Com flex-wrap: wrap;, eles podem quebrar para a próxima linha quando falta espaço. A propriedade flex controla como cada item cresce, encolhe e define seu tamanho base.

.container {
  display: flex;
  flex-wrap: wrap;
  gap: 0.75rem;
}

.item {
  flex: 1 1 130px; /* crescer, encolher e tamanho base */
}

A forma abreviada flex: 1; distribui o espaço disponível entre os itens. order altera a ordem visual de um item, mas não muda a ordem do HTML nem a sequência de leitura para tecnologias assistivas.

Quando usar Flexbox?

Flexbox funciona muito bem para componentes em uma dimensão, como barras de navegação, grupos de botões, menus, cartões em uma linha e alinhamento de conteúdo. Para controlar simultaneamente linhas e colunas de uma página, considere CSS Grid.

Atividade prática

Crie uma barra de navegação com três links e pratique:

  • centralizar os itens com justify-content;
  • alinhar os itens verticalmente com align-items;
  • adicionar espaçamento com gap;
  • fazer os itens quebrarem de linha em telas menores com flex-wrap.
