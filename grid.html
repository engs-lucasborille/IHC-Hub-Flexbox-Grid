O que é CSS Grid?

CSS Grid é um sistema de layout bidimensional: permite organizar elementos em linhas e colunas ao mesmo tempo. O elemento pai define a grade e seus filhos diretos podem ocupar uma ou mais células.

Ative o Grid no contêiner com display: grid;. Em seguida, defina suas colunas e linhas com grid-template-columns e grid-template-rows. 

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 12px;
}

Colunas, linhas e a unidade fr

A unidade fr representa uma fração do espaço disponível. A função repeat() evita repetir valores. A demonstração abaixo cria três colunas iguais e duas linhas; o Grid posiciona os itens automaticamente.

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, auto);
  gap: 12px;
}

Grades responsivas

Combine repeat(), auto-fit e minmax() para criar colunas que se adaptam ao espaço disponível. Cada coluna terá pelo menos 120px e poderá crescer para ocupar o espaço restante.

.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(120px, 1fr));

Posicionando e alinhando itens

As linhas da grade podem ser usadas para definir onde um item começa e termina. grid-column controla a posição entre colunas e grid-row entre linhas. O item em destaque a seguir ocupa duas colunas.

.destaque {
  grid-column: span 2;
}

Para alinhar o conteúdo das células, use justify-items (horizontalmente) e align-items (verticalmente). Para alinhar toda a grade dentro do contêiner, use justify-content e align-content.

Áreas nomeadas

grid-template-areas permite nomear regiões da grade e atribuí-las aos itens com grid-area. Esse recurso ajuda a visualizar e reorganizar estruturas de página, como cabeçalho, menu, conteúdo principal e rodapé. 

.pagina {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-areas:
    "cabecalho cabecalho"
    "menu      conteudo"
    "rodape    rodape";
  gap: 12px;
}

.cabecalho { grid-area: cabecalho; }
.menu      { grid-area: menu; }
.conteudo  { grid-area: conteudo; }
.rodape    { grid-area: rodape; }

Quando usar Grid?

Grid é indicado para estruturas bidimensionais, como a composição de uma página, galerias e painéis com linhas e colunas relacionadas. Para alinhar um grupo de elementos em uma única direção, Flexbox pode ser mais simples. Os dois recursos também podem ser combinados.

Atividade prática

Monte uma galeria de cartões e pratique:

  • criar três colunas com repeat(3, 1fr);
  • adicionar espaçamento entre as células com gap;
  • fazer um cartão ocupar duas colunas com grid-column: span 2;
  • adaptar a quantidade de colunas usando auto-fit e minmax().
